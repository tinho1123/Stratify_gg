Compact status pill / count label in a semantic hue. Used for player availability, roles, market tags, and counts.

```jsx
<Badge tone="emerald" dot>Online</Badge>
<Badge tone="danger" dot>Lesionado</Badge>
<Badge tone="warning">Suspenso</Badge>
<Badge tone="info" variant="solid">IGL</Badge>
<Badge tone="pink" size="sm">AWPer</Badge>
```

`variant="soft"` (default) is a tinted fill + ring; `solid` is full color. `dot` adds a leading status dot. Tones map to the semantic palette (emerald/danger/warning/info/pink/neutral).
