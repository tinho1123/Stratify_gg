Circular header control for icon-only actions — back, notifications, profile avatar slot.

```jsx
<IconButton ariaLabel="Voltar">‹</IconButton>
<IconButton badge={3} ariaLabel="Notificações">🔔</IconButton>
<IconButton variant="accent">GS</IconButton>
```

Variants: `control` (dark chip + border), `accent` (emerald), `ghost`. `badge` adds the red unread counter. Hover brightens, press scales to 0.92.
