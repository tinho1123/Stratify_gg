Square overall-rating chip for player cards; fill color scales with the score.

```jsx
<RatingBadge value={94} />        {/* elite — emerald */}
<RatingBadge value={82} size="lg" /> {/* good — blue */}
<RatingBadge value={68} size="sm" /> {/* weak — red */}
```

Tiers: ≥90 emerald, ≥80 blue, ≥70 amber, else red. Numerals are tabular mono.
