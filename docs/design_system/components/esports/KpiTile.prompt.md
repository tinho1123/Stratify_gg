Compact metric tile for the dashboard KPI grid (place 2-up).

```jsx
<KpiTile icon="🏆" value="12º" label="Ranking" tone="warning" delta="+3" />
<KpiTile icon="💰" value="$8.4M" label="Orçamento" tone="emerald" />
<KpiTile icon="🎯" value="64%" label="Win Rate" delta="-2%" />
```

`delta` sign sets the arrow and green/red color. `value` is mono/tabular.
